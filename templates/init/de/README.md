# Validierung

Anforderungen, Ablauftests und Testbericht, erstellt mit
[@atwx/validation-kit](https://github.com/atwx/validation-kit).

```bash
npm install
npx playwright install chromium
npm run check      # Katalog, Zitate, Verhaltensinventar
npm run validate   # Prüfung, Ablauftests, HTML-Bericht in report-out/
npm run report:fb  # FriendlyBase-Paket in report-fb/
```
