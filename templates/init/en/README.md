# Validation

Requirements, flow tests and the validation report, built with
[@atwx/validation-kit](https://github.com/atwx/validation-kit).

```bash
npm install
npx playwright install chromium
npm run check      # catalogue, quotes, behaviour inventory
npm run validate   # check, flow tests, HTML report in report-out/
npm run report:fb  # FriendlyBase package in report-fb/
```
